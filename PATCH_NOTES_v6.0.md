# LoftDesk v6.0 — Core Flow & Document Polish

## Najważniejsze zmiany

- uproszczone menu do głównego flow: **Tablica / Kontrahenci / Wycena / Umowa / Faktura / Portal / Projekty / KSeF / Ustawienia**
- odchudzony, bardziej elegancki layout i subtelniejsza kolorystyka
- dashboard przebudowany pod 5 głównych akcji użytkownika
- przy kartach wycen dodane szybkie akcje **Umowa / Faktura / Projekt** dla zaakceptowanych wycen
- umowa może zostać utworzona z wyceny z automatycznym podpięciem kontrahenta i kwoty
- formularz umowy bez edycji HTML: gotowe wzory + dodatkowe ustalenia + transze
- projekty i faktury przenoszą relację do wyceny (`estimate_id`) w warstwie aplikacji
- szczegóły projektu pokazują powiązaną wycenę, budżet, koszty i marżę
- dokumenty (wycena / umowa / faktura / protokół) mają nowy, lżejszy wzór pod podgląd i wydruk
- w podglądzie dokumentu: **Pobierz wzór / Pobierz XML / Drukuj / zapisz PDF**
- ukryte i wysmuklone scrollbary, ciaśniejsze spacingi, mniejsze przyciski i karty
- teksty w ustawieniach uproszczone pod laika

## Uwaga praktyczna

Stylizowany zapis PDF działa przez opcję **„Drukuj / zapisz PDF”** z podglądu dokumentu.
Eksport XML pozostaje bezpośredni.
